# 同轴线单位长度电容推导

设内导体半径为 a，外导体内半径为 b，且 b > a。两导体间充满均匀、线性介质，介电常数 ε = ε₀εᵣ。忽略端部效应，导体视为理想导体，内外导体单位长度电荷分别为 +λ 和 −λ。

## 1. 选取高斯面

取半径 r、长度 L 的同轴圆柱面，其中 a < r < b。由圆柱对称性，介质中电场沿径向，同一半径处电场大小相等，两端面的电通量为零。

## 2. 由高斯定理求电场

∮ D·dS = Q = λL

εE(r)·2πrL = λL

所以 E(r) = λ/(2πεr)，方向由内导体指向外导体。

## 3. 求内外导体间电势差

U = V(a) − V(b) = ∫ₐᵇ E(r)dr

  = [λ/(2πε)]∫ₐᵇ dr/r

  = [λ/(2πε)]ln(b/a)

## 4. 求单位长度电容

C = Q/U = λL/U = 2πεL/ln(b/a)

因此 C′ = C/L = 2πε/ln(b/a) = 2πε₀εᵣ/ln(b/a)

单位为 F/m，ln 为自然对数。手写时画同轴横截面，标出内导体半径 a、外导体内半径 b 和介质 ε。
